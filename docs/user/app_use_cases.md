# Using the App

This document describes common use-cases and scenarios for this App.

## General Usage

Use this app to build temporary, source-of-truth-driven lab environments for testing changes before production deployment.

## Use-cases and common workflows

- Stand up a digital twin for a site to validate cabling and topology intent.
- Push generated intended configurations to already running twin devices.
- Re-deploy and compare outcomes after changing Nautobot source-of-truth data.
- Use auto-destroy to keep labs ephemeral and cost-efficient.
